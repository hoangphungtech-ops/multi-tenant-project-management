# API Overview

Base path: `/api/v1`

Workspace:
- `POST /tenants/{tenantId}/workspaces`
- `GET /tenants/{tenantId}/workspaces`
- `GET /tenants/{tenantId}/workspaces/{id}`
- `PUT /tenants/{tenantId}/workspaces/{id}`
- `DELETE /tenants/{tenantId}/workspaces/{id}`

Export:
- `POST /tenants/{tenantId}/exports`
- `GET /tenants/{tenantId}/exports/{jobId}`

Interactive OpenAPI: `/swagger-ui.html`.
